Court box on a Raspberry Pi 5

The WeMos Mega 2560 + ESP8266 board comes out and one Raspberry Pi 5 goes in. Relays, buttons, LCD, scanner and power supply all stay. The Pi runs the court box's existing, tested firmware logic as two Linux processes, so the box behaves exactly as it does today.

court-io = Mega 3.0.0 logic court-brain = bridge 3.1.0 logic serial protocol v3, unchanged device API v3, unchanged
What changes

Two chips become two processes

The Mega kept the lights safe when the ESP crashed because they were separate chips. On the Pi they are separate processes with no shared memory, talking the same v3 bytes over a Unix socket instead of Serial3. The C++ under court-box/lib and court_bridge/main.cpp is compiled as-is; only the hardware layer is new.

Electrical

Wiring schematic

The Pi's GPIO is 3.3 V and not 5 V tolerant, so every 5 V part reaches it through an interface: a BSS138 shifter for the LCD and scanner, a 74AHCT125 buffer for the SSR inputs. Buttons switch to ground and use the Pi's own pull-ups, as on the Mega.

Pi 5 specifics

  • Scanner on UART0, /dev/ttyAMA0, with dtparam=uart0=on. On a Pi 5, /dev/serial0 is the separate debug connector.
  • GPIO is on the RP1 chip; court-io finds it by label, because its number changed between kernels.
  • 5.1 V 5 A into USB-C, with usb_max_current_enable=1 since a buck cannot negotiate USB-PD.
  • Active Cooler: the load is light, a sealed box in summer is not.
Polarity is now set by a resistor. The club's SSRs trigger active-high, so the resistors pull down. If an active-low module were ever fitted, swap them to pull-ups and set hw_relay_active_level to low; the box still fails dark.

Parts

What stays, what goes, what's new

Stays

  • Mean Well PSU and the fused LM2596 5 V rail
  • 4 SSRs and whatever they switch (contactors)
  • 8 panel buttons (4 green, 4 black)
  • LCD 2004/1602 with PCF8574 backpack
  • QR scanner, enclosure, glands

Goes

  • WeMos Mega 2560 + ESP8266 board
  • The 8-way DIP switch and its procedure
  • The 9 V rail, if it only fed the Mega
  • Arduino IDE flashing at the box

New

  • Raspberry Pi 5, 2 GB (a Pi 4 or 3B+ runs the same build as a spare)
  • Official Active Cooler
  • 32 GB high-endurance microSD
  • Fused 5.1 V 5 A buck + USB-C pigtail
  • 74AHCT125 quad buffer + 100 nF
  • 4-channel BSS138 level shifter
  • 4 × 10 kΩ, 1 × 330 Ω; GPIO screw-terminal breakout
Install

Commissioning order

  1. Fit the Active Cooler. Flash Raspberry Pi OS Lite (64-bit, Bookworm or later) to the card; enable SSH with a key, set the WiFi or plug in Ethernet.
  2. Wire the board with the mains isolated. Before connecting the SSRs, check each buffer output reads 0 V with the Pi powered off and booting.
  3. Clone the repo on the Pi, copy court-pi/config/common/secrets.h.example to secrets.h and fill in the four values.
  4. Run sudo src/iot/court-pi/deploy/install.sh, then reboot.
  5. To keep the old box's court numbers and button map, put the ESP8266's MAC in COURT_BRAIN_MAC in /etc/court-box/court-box.env. Never run both boxes at once.
  6. Watch journalctl -u court-io -u court-brain -f; the Devices page should show firmware 3.1.0 and Mega 3.0.0 within one heartbeat.
  7. Run the go-live bench checks: pull the power mid-game, kill -9 each process, confirm every court goes dark or times out as the table above says.
