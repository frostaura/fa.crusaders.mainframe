# A note on the Minimal API entries: lizard scores `MapXxxEndpoints` as one
# function, but it is really N independent route handlers, each individually
# simple. Those are measurement artifacts rather than genuine complexity, and
# they resolve naturally as endpoints are split out during the device work.
#
# THE NAMES HERE ARE LIZARD'S, NOT C#'s, and the two can disagree. lizard's C#
# parser scopes a function under the most recently DECLARED type, not the type
# that encloses it: a method sitting below a nested class is reported under the
# NESTED class's name. So an entry is only ever correct relative to where the
# nested types in that file happen to sit, and MOVING a nested class silently
# voids the entry — the gate goes red on a file nobody edited, or a whitelisted
# function quietly stops being ratcheted. Copy the name out of
# `make complexity`'s warning line; never type it from the C#, and re-run the
# gate after moving any nested type.
