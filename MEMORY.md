# MEMORY — Technologies/projects/crusaders.mainframe

- [Red — the relay question is an electrical safety matter, and it is unanswered](memory/safety-relays.md) — RED: nobody has established whether the court relays switch a contactor coil or the lighting load directly. If direct, an electrician is needed before anything ships — no software decision touches this, and it gates go-live.
- [Current state](memory/state.md) — The whole build sits on claude/e2e-fix-programme, pushed 2026-09-16 and in sync; main is far behind it and the merge is the open act, with PR #2 still a draft, so the release half has never executed. No hardware, no deploy, no paying club.
- [Live decisions — product and economics](memory/decisions.md) — Product and economics: blueprint Rev 2 is the customer's word and outranks internal specs; credits are the unit of account; charge AT BOOKING supersedes charge-on-lights-on and still needs committee sign-off; PayFast replaced Peach.
- [Live decisions — the device contract and firmware](memory/decisions-device.md) — The device contract is hobby-grade by founder decision — one per-tenant API key, auto-registration, no OTA or discovery; the brains are on the ESP8266 because the Mega cannot be flashed over WiFi; the wiring is fixed and untouchable.
- [Live decisions — the door gate](memory/decisions-door-gate.md) — One pull-only ESP32 per door, one image for every door; only a 200 is an answer and a 200 refusal is never second-guessed; the lock is asserted LOCKED before its pin is an output; it is wired fail-secure where the owner asked for fail-safe.
- [Live decisions — how quality is proven here](memory/decisions-method.md) — Quality here is proven by refutation, not by a green suite: every fixer is followed by an agent paid to disprove it, rounds repeat until two consecutive ones find nothing high, and parallel lanes are scoped by FILE, never by theme.
- [Live decisions — settlement and the ledger](memory/decisions-settlement.md) — How the ledger settles: a no-show releases its tail by truncating EndsAt, late box evidence reverses it with two NEW rows (never an edit, balance may go negative), the resold tail is displaced, offline scans judged at scan time.
- [Gotchas — the test suite and its fixtures](memory/gotchas.md) — The test suite lies in specific ways: it cannot pass in the last half-hour of a UTC day, some tests cannot fail on this Mac by construction, a test can be green because of one fixture field, and the in-memory provider has no transactions.
- [Gotchas — the firmware toolchain](memory/gotchas-build.md) — Firmware toolchain traps: src/iot is several PlatformIO projects sharing one venv, court-box/arduino/ is GENERATED and self-asserting, anything court_mega links must be valid C++11 as well as C++17, and a library coordinate is owner/name.
- [Gotchas — this machine and this iCloud checkout](memory/gotchas-env.md) — This checkout sits on iCloud: MSBuild is denied copying appsettings into bin, iCloud fabricates numbered duplicates inside generated sketches, and a worktree under .claude/ inherits a hidden flag that makes .NET ignore appsettings.json.
- [Gotchas — frontend, vitest and the browser harness](memory/gotchas-frontend.md) — React and browser-harness traps: renderPage(<StrictMode>…) is INERT so lanes wrote tests they believed were guarded, user-event's keyboard path hangs under jsdom 28, and only the repo's own Chromium can register a service worker.
- [Gotchas — the quality gates and their lint tooling](memory/gotchas-gates.md) — Several quality gates report a red run as green or trip on a function nobody wrote: complexity exits 1 on stdout, lizard's C# and .tsx lexers mis-scope, the rollover grep keys on names, and ls-files misses untracked work.
- [Open questions](memory/questions.md) — All founder-owned and none of them technical: PIN length (a 4-digit collision charges the wrong member), biometric vendor SDK, gate policy, revoked-card window, pricing beyond Crusaders, and whether the club goes live this quarter.
- [Watch list](memory/watch.md) — Unpaid debts, worst first: .env holds live JWT, database, SMTP and device secrets unencrypted and unbacked-up; the Portainer secrets are unset so the release chain has never run; charge-at-booking is unsigned-off.
